## Feature Analysis by Solution

### Sweep

**Core features**
- Scope 1, 2, and 3 GHG accounting aligned to GHG Protocol
- Multi-framework reporting: CSRD, CDP, GRI, ISSB, SFDR, TCFD, SB 253 from a single data model
- AI-powered emissions hotspot identification and predictive analytics
- Supplier portal for Scope 3 data collection with direct supplier input and target tracking
- Audit-ready outputs with embedded compliance logic
- Role-based access and multi-entity data model for complex organisational structures
- Approval workflows for data sign-off and assurance preparation

**Differentiating features**
- Flexible data model that adapts to any organisational structure rather than forcing a rigid schema
- Treats ESG data as structured business intelligence rather than a compliance output
- Named as a Leader in 2026 Verdantix Green Quadrant for Enterprise Carbon Management and Product Carbon Footprinting

**UX patterns**
- Dashboard-centric interface surfacing emissions hotspots and reduction opportunities
- Supplier self-service portal reduces internal data collection effort
- Progressive framework mapping — one dataset populates multiple disclosure templates

**Integration points**
- API connectors to energy management systems
- Supplier engagement portal (web-based, no supplier software required)
- Enterprise data imports (CSV, API)

**Known gaps**
- Pricing is enterprise-tier, limiting accessibility for mid-market organisations
- Product carbon footprinting (PCF) is a separate module not always included in base subscription

**Licence / IP notes**
- Proprietary SaaS; no open-source components disclosed

## Cross-Cutting Feature Themes

### Table-Stakes Features
- Scope 1, 2, and 3 GHG calculation using GHG Protocol methodology
- Multi-framework reporting output (minimum: GRI, CSRD, ISSB/TCFD, CDP)
- Emissions factor library with versioning and regular updates
- Audit trail linking each disclosed figure to its source data
- Role-based access control and approval workflows
- Data import via CSV and at least one major ERP connector
- Target setting and progress tracking against net-zero or SBTi targets
- Supplier data collection portal or survey mechanism

### Differentiating Features
- AI-native document ingestion (OCR, LLM-based categorisation) reducing manual data entry
- Natural language query interface (Copilot, GPT-style) for sustainability insights
- Ledger-style data model providing financial-grade auditability (Persefoni)
- Unified financial + ESG + GRC platform (Workiva)
- Analyst-validated supplier ratings network at scale (EcoVadis)
- Product carbon footprinting (PCF) at SKU or asset level
- Real-time Scope 3 supplier emissions tracking (beyond annual surveys)
- Decarbonisation scenario modelling with abatement cost curves

### Underserved Areas / Opportunities
- **SME accessibility**: Enterprise pricing ($50k–$200k/yr) locks out the large mid-market segment where most Scope 3 emissions actually originate; affordable, self-serve tools remain limited
- **Real-time Scope 3 data**: Most platforms rely on annual supplier surveys; automated, transaction-level Scope 3 calculation from procurement data is nascent
- **Social and governance (S and G) data collection**: Carbon-centric platforms struggle to extend credibly into labour, human rights, and governance disclosures; the full ESG data model is underserved
- **Emission factor transparency and interoperability**: Proprietary factor libraries create lock-in and make cross-platform auditing difficult; an open, versioned factor database would differentiate
- **AI-assisted materiality assessment**: CSRD and ESRS require a double materiality assessment; no platform automates this process meaningfully
- **Regulatory change tracking**: Standards evolve faster than annual release cycles; automated framework update propagation is poorly solved
- **Narrative disclosure drafting quality**: AI drafting exists but quality is inconsistent; LLM-powered narrative generation aligned to assurance standards is an open problem
- **Interoperability and data portability**: Customers are locked into proprietary data models; standardised ESG data exchange formats are immature

### AI-Augmentation Candidates
- Document ingestion: OCR + LLM classification of utility bills, invoices, and supplier documents
- Emissions factor matching: NLP-based mapping of activity descriptions to correct GHG Protocol categories and factors
- Anomaly and error detection: ML models flagging outliers in emissions data before submission
- Narrative report drafting: LLM generation of CSRD/GRI disclosure responses from structured data
- Double materiality assessment: AI-assisted stakeholder impact and financial risk scoring across ESG topics
- Supplier engagement: Automated reminder workflows, data quality scoring, and gap analysis for Scope 3
- Regulatory change monitoring: NLP-based tracking of standard updates and automatic framework mapping refresh
- Scenario modelling: AI-generated abatement pathways ranked by cost-effectiveness and feasibility

## Legal & IP Summary

All major platforms in this space are proprietary commercial SaaS products with no open-source licensing. Emissions factor databases are generally proprietary (IBM Envizi, Watershed, Persefoni), though Normative discloses its underlying sources and Greenly references GHG Protocol alignment. The GHG Protocol itself is freely available under Creative Commons. EcoVadis's scoring methodology is a trade secret. No patents on core ESG reporting workflows were identified in this survey, though AI-specific claims (Persefoni's emissions factor matching, Watershed's agent architecture) may be subject to patent filings. An open-source platform building on public emissions factor databases (IPCC, IEA, ecoinvent where licences permit) and open standards (GHG Protocol, GRI, ISSB) would face no licensing barriers to core functionality.
